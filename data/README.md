# Input data

Put custom RAW inputs here and provide dimensions, dtype and spacing explicitly.
The existing skull_256x256x256_uint8.raw and skull/ files were moved from the
repository root without changing their contents. skull/ is a historical export,
not the current grouped pipeline output.

New custom RAW inputs are ignored by Git. Large downloaded examples and generated
payloads live in experiments/large-volumes/, also ignored. See the root README.
No new license or provenance claim is made for the historical Skull files.
